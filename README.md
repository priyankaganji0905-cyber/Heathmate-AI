# HealthMate 2.0

AI-assisted elderly health monitoring and analytics system.

## Problem Statement
Elderly individuals often face difficulties in continuously monitoring health parameters
and adhering to medication schedules. HealthMate aims to provide a simple, data-driven
solution to track vitals, analyze trends, and assist in early health-risk identification.

## Current Status
This project is being rebuilt from a hackathon prototype with a focus on analytics and
AI-based insights.

## Planned Features
- Patient profile management
- Medication reminders
- Health vitals tracking
- Data visualization dashboard
- Basic risk prediction (future scope)

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Data & Analytics: Pandas, NumPy
- Visualization: Matplotlib / Chart.js
- Version Control: Git & GitHub
